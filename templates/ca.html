Only the root and intermediates created with "Allow sub-CAs" are listed.

About intermediate CAs and purpose selection

An intermediate CA is a certificate authority that sits between the root CA and end-entity certificates. Its configuration determines what it can issue. A leaf-only intermediate can only issue end-entity certificates. An intermediate configured to allow sub-CAs can issue both end-entity certificates and other intermediate CAs, creating a nested hierarchy. A dedicated SCEP intermediate is a special-purpose CA for Simple Certificate Enrollment Protocol, used for automated device enrollment; it must be RSA-based (for encryption) and leaf-only, and will have the keyEncipherment key usage added automatically.
